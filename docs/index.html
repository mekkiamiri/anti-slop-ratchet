Contre l'AI slop :
un linter Java qui apprend des revues

L'agent écrit du code qui compile, passe les tests et semble moderne. La revue trouve un anti-pattern. On le dit à l'agent ; il en introduit un autre. Et si chaque remarque de revue qui revient devenait une règle qui casse le build ?

Le prompt suggère, la règle s'impose. Ci-dessous : 11 règles ArchUnit, chacune née d'une remarque de revue, avec le mauvais code, le bon code et la règle. Toutes tournent et sont testées dans le dépôt.
